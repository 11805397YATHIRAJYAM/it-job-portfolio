# IT Job Portfolio — MERN Stack Developer

Responsive dark-themed React portfolio for a fresher targeting MERN Stack Developer roles.

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000.

## Folder structure
- `public/` — static public files
- `src/components/` — Navbar, Hero, About, Skills, Projects, Journey, Contact and Footer
- `src/data/` — project and skills content
- `src/assets/images/` — profile photo, LinkedIn banner and other images
- `src/assets/icons/` — custom icons
- `src/styles/` — global CSS
- `src/App.js` — assembles the page sections
- `src/index.js` — React entry point

## Personalize before publishing
1. Replace `Your Name` in `src/components/Hero.js` with your name.
2. Replace `your.email@example.com` in `src/App.js` and `src/components/Contact.js`.
3. Update LinkedIn and GitHub links in `src/components/Contact.js`.
4. Update project repository/demo URLs in `src/data/portfolioData.js`.
5. Add education, certifications, graduation year and resume link when ready.
6. Add profile and banner images to `src/assets/images/` when available.

## Commands
- `npm install` — install dependencies
- `npm start` — start development server
- `npm run build` — create production build

Built with React 18 and Create React App (`react-scripts`); no Vite.
